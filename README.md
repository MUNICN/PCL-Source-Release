## 版本对应

本版版本号与所基于的官方版保持一致，当前基于 **PCL 2.99.0.1**（VersionCode 415）。

官方发新版本时这个仓库跟着更新，版本号始终对齐，方便对照——看到 `2.99.x.x` 就知道改的是哪一版。

## 改了什么

1. **微软 Client ID 自己填** —— 启动页「正版」界面底部有输入框和「确定」。本版**不内置任何 Client ID**，第一次用正版登录前必须填一个，否则会被拦下。旁边有「怎么获取 Client ID」，点开是教程加一键跳转。
2. **解除下载限制** —— 官方 `RestrictMcDownload` 为 `True`，本版改为 `False`，原版游戏下载可用。
3. **补全百宝箱** —— 今日人品、内存优化、清理游戏垃圾、千万别点、回声洞、下载自定义文件，界面和交互照官方版复刻。回声洞的 736 条留言是从官方发布版里提取的原始数据。
4. **单文件打包** —— 依赖的 dll 以资源形式嵌进 exe，运行时从内存加载，分发只需要一个 exe。
5. **分支标识改为 `PCLMod`** —— 原来的 `OpenSource` 会弹「该版本中无法使用以下特性」，本版不弹，也不冒充 `Official`。

## 第一次用之前：申请自己的 Client ID

微软用它分辨「哪个程序在登录」，登记一次就行，免费、不审核。

1. 打开 https://portal.azure.com ，用你自己的微软账号登录（个人号就行）
2. 搜「应用注册」，点「新注册」
3. 名称随便写，比如 `PCL`
4. 「支持的账户类型」选第二个：**仅个人 Microsoft 账户**
5. 注册完进入应用页，复制「应用程序(客户端) ID」
6. 粘进启动器的输入框，点「确定」

不用配重定向地址，不用申请接口权限，也不用生成密钥。也可以设环境变量 `PCL_MS_CLIENT_ID`，优先级低于手动填写。

## 怎么编译

需要：

- Visual Studio Build Tools 2022（提供 MSBuild 和 WPF 编译目标）
- .NET Framework 4.8 引用程序集
- .NET SDK 8 或更高（MeloongCore 用了 C# 13 语法）

双击根目录的 `build.bat`，产物在 `Plain Craft Launcher 2\bin\`。

> `build.bat` 里的 MSBuild 路径写死了，装在别的位置要自己改。

## 一个技术上的说明

`OAuthClientId` 默认返回空字符串，不是漏写。PCL 官方仓库里这个字段也被特意挖空了，作者并不打算让人随便拿去用。自己申请一个的成本是十分钟，换来的是不用看别人脸色——哪天作者换了 ID，用官方 ID 的二改版会集体失效，自己申请的不会。
